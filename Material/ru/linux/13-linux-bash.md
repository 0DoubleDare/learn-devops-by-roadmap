bash - базовый интерпритатор команд который присутствует на любом линуксе. Позволяет создавать скрипты и атвтоматизировать рутину. 


# Синтаксис
Любой скрипт начинается с так называемого "шебанга" который указывает системе через какую командную оболочку запускать скрипт:
```bash
# Жестко указываем что используем bash

#!/bin/bash

# Более гибкий вариант, если bash есть в системе (в /bin/ или /usr/bin/) - то  
# запустит скрипт через него,
# а если нет - то выдаст понятную ошибку

#!/usr/bin/env bash
```
## Переменные
В bash в отличие от других языков программирования всего 4 основных типа данных:

**Строки (Strings)** - базовый тип, в него можно записать текст, числа, пути к файлам или вывод других команд

**Целые числа (Integer)** - для них нет отдельно типа данных, но bash умеет выполнять базовую арифметику

**Массивы** - хранят список элементов. Существа два типа массиов - индексируемые и ассоциативные.
```bash
#!/bin/bash

# Пример индексируемого массива
services=("nginx", "docker", "gitlab")
# Обращение к элементам проводится с помощью указания индекса.
echo "${services[0]}"
> nginx
# Также можно вывести все элементы массива
echo "${services[@]}"
> nginx docker gitlab

# Пример ассоциативного массива
# Обязательно, объявляем переменную как ассоциативный массив
declare -a gitlab_config
gitlab_config[user]="0DoubleDare"
gitlab_config[password]="MegaPassword213"
```

**Логический тип (Boolean)** - в bash **нет** значений true / false, вместо этого bash оценивает код возврата (Exit status) где значение 0 - успех (*true*), а остальные (от 1 до 255) - ошибка / неудача (*false*).

В bash переменные объявляются следующим образом:
```bash
#!/bin/bash

# Объявдение переменной. Переменная всегда должна писаться слитно с знакоми равно и значением
LOCALHOST="127.0.0.1"
ip_addrs_count=4
path="/var/log/nginx"

# ОШИБКА: Пробелы недопустимы
LOCALHOST = "127.0.0.1"
```
Также переменные можно выводить и записывать в них ввод с клавиатуры:
```bash
#!/bin/bash

read -p "Введите адрес вашего локального хоста: " LOCALHOST 

# Если вызвать команду без указания переменной, то ввод запишется в стандартную # переменную окружения $REPLY
read -p "Введите порт хоста: "
echo "Ваш порт: $REPLY"
```

Важные флаги команды `read`
`-p` (Prompt) - текст-приглашение для пользователя, добавляет интерактива
`-s` (Secret / Silent) - скрывает символы при вводе
`-t <время в секундах>` (Timeout) - Задает время ожидания в секундах, если пользователь не ввел значение спустя заданное время то скрипт продолжит работу. Нужно чтобы избеать зависание скрипта
`-r`  (Raw) - отключает обработку экранирорания. Это означает что `\n` не будет считаться как перенос строки
`-a`(Array) - Разбивает ввод с клавиатуры на элементы массива, в качестве разделителя используются *пробел* и *знак табуляции*
```bash
read -p "Требования: " -a requirements
echo "${requirements[@]}"
```

## Условия и ветвления
В bash доступно два условных оператора - *if* и *case*. Сначала рассмотрим конструкцию *if*
```bash
#!/bin/bash

if [ some==10 ]; then
	# Команды...
	echo "10"
elif [ some!=20 ]; then
	# Команды...
	echo "20"
else 
	# Команды...
	echo "empty"
# Обязательное закрывающее "fi"
fi
```
Само условие задается в квадратных скобках `[ условие ]`. Как и в других языках программирования в bash можно сравнивать но с некоторыми отличиями. В bash есть два способа сравнения - через выражения или математически.
`-lt` (**L**ess **T**han) - Меньше чем (<)
`-gt` (**G**reater **T**han) - Больше чем (>)
`-le` (**L**ess or **E**qual) - Меньше или равно (<=)
`-ge` (**G**reater or **E**qual) - Больше или ровно (>=)
`-eq` (**E**qual) - Равно (\==)
`-ne` (**N**ot **E**qual) - Не равно (!=)
```bash
#!/bin/bash

$a = 10
$b = 5

if [ "$a" -lt "$b" ]; then
	echo "$a меньше чем $b"
elif [ "$a" -gt "$b" ]; then
	echo "$a больше чем $b"
fi
```
Если вам привычнее использовать классические **матетимачесикие** знаки сравнения 
(`>`, `<`, `>=`, `<=`, `==`) то в условии вместо квадратных скобок пишутся двойные круглые:
```bash
#!/bin/bash

$a = 10
$b = 5

if (( "$a" < "$b" )) ; then
	echo "$a меньше чем $b"
elif (( "$a" > "$b" )); then
	echo "$a больше чем $b"
fi
```

> [!WARNING] Отличия между конструкциями
> Выбор между `[ ]` и `(( ))` не самый очевидный и имеет свои особенности.
> 
> **Проблемы при условии в `[ ]`**
> 1. Скрипт упадет если переменная в условии окажется пустой:
> 	```bash
> 	 #!/bin/bash
> 	
> 	 # Если $a окажется пустой, то bash воспримет строку как 
> 	 # "if [ -lt 10 ]" что вызовет ошибку
> 	 if [ $a -lt 10 ]
> 	
> 	 # Дабы избежать этого, объявляйте переменную в ковычках. Если значение 
> 	 # окажется пустым то bash воспримет переменную как пустую строку 
> 	 if [ "$a" -lt 10 ]
> 	```
> 2. Полный запрет на дробный числа. Bash не умеет работать с числами с плавающей точкой
> 3. Путаница со строками. Если вы воспользуйтесь оператором сравнения со строкой то bash попытается перевести её в число, что может вызвать непредсказуемое поведение.
> 
> **Проблемы при условии в `(( ))`**
> 1.  Ловушка 0 и 1. Если в bash 0 - это успех, в другое число - ошибка, то в математике всё наоборот. 
> 	```bash
> 	 #!/bin/bash
> 	 a=0
> 	 (( a == 0 )) # 0 == 0, это ОК
> 	 
> 	 (( a )) # переменная вернет 0, это ЛОЖЬ и bash вернет Exit code 1
> 	```
> 1. Совместимость. Конструкция `(( ))` это особенности Bash, Zsh и Ksh. Если ваш скрипт запустят на чистом POSIX-шелле то скрипт упадет с ошибкой. Это может стать проблемой если на сервере скрипт запускается через оболочку sh которая не поддерживает `(( ))` или при запуске внутри докера с alpine-линуксом где bash'а нет вообще.
