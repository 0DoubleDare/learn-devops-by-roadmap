## Основные определения
**PID** (Program IDentifier) процесса - уникальный идентификатор (ID) запущенного процесса в системе.
**FD (File Descriptor)** - файловый дескриптор, представляет из себя положительное целое число. Это как порядковый номер и выдается файлам, сетевым сокетам, каналам (пайпам), устаройствам (клавиатура, видеокарта) и директорию. Это нужно чтобы ядру было легче обращаться к элементу в системе. При этом у **каждого** процесса при инициализации есть файловые дескрипторы по умолчанию - 0, 1, 2.
0 (stdin) - стандартная библиотека для ввода данных
1 (stdout) - стандартная библиотека для вывода данных
2 (stderr) - стандартная библиотека для вывода ошибок.
Понимание файловый дескрипторов поможет при изучений перенаправлений ввода.
